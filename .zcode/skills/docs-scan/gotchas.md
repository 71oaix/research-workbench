# /docs-scan 踩坑记录

## G001：不要对 docs/ 不存在的项目报错

如果项目没有 `docs/` 目录，正常跳过并提示"无 docs 目录，跳过"，而不是报错退出。

## G002：不要自动移动文件（即使看起来明显）

文件移动需要用户确认，不能自动执行。因为 agent 判断的"目标目录"可能违反用户的本意。

## G003：INDEX.md 格式差异处理

不同项目的 INDEX.md 可能有自定义列（如加了"负责人"列）。扫描时以第一行为准识别列映射，不要假设固定列数（默认 3 列，项目可自定义）。

## G004：不要修改 frontmatter 的业务字段

`title`、`tags` 等字段即使看起来可以优化，也不能自动修改——这些是业务语义字段，用户可能有自己的命名逻辑。

## G005：空文档 ≠ 空文件

一个 .md 文件可能只有 frontmatter 没有正文内容（H1 后无内容），这是合法的空文档，不是损坏文件。只有 `---` 都不存在的真正空文件才算 #7。

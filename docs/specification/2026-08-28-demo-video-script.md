# 研镜 · 演示视频脚本（4 分 30 秒版本）

> 录制方式：1080p 屏幕录制 + 旁白（可后期配音或用字幕替代）；浏览器缩放 125%；
> 关闭系统通知；录前 10 分钟跑一次冒烟确保服务健康。

## 预备清单（录制前）

- [ ] 后端 :3000 + 前端 :5173 已启动（普通模式带 key）
- [ ] 预置两条工作流作为"历史记录"：一条 completed 七步流程、一条含打回迭代的
- [ ] 浏览器新开无痕窗口，收藏栏只留 localhost:5173
- [ ] 录屏工具（OBS / Xbox Game Bar）分辨率 1920×1080@30fps 起

## 分镜脚本

| # | 时间 | 画面 | 旁白 / 字幕 |

| 1 | 0:00-0:25 | 标题卡 → 切工作台空态界面 | "文献调研占科研时间的三成以上，而通用大模型生成的综述，引用可能是幻觉。这是研镜——一个全流程透明、每句引用可溯源的学术调研智能体工作台。" |
| 2 | 0:25-1:00 | 空态大输入框输入宽泛问题「研究下多智能体的记忆架构」→ 提交 → 出现澄清审批卡（列出锚点问题） | "问题太宽泛？不着急搜。规划角色会先要求澄清研究锚点——我在意见框里补充领域、范围与时间，点击'提交回答并重新规划'。" |
| 3 | 1:00-1:40 | 计划产物展开（子问题/检索关键词/大纲），点通过 → 自动跳到检索步骤，实时命中数上涨 | "澄清后生成结构化检索计划：六个子问题、双语关键词、综述大纲。我确认后放行，四个学术数据源并发检索，命中上千篇。" |
| 4 | 1:40-2:30 | research-candidates → selector 卡片（相关度分级+理由）→ coverage-matrix 展开，指着一行「partial（模型复核）」 | "筛选角色逐篇判定相关度并给出理由。关键创新在这里：覆盖矩阵逐个子问题检查文献支撑——规则判定之上还有模型精判，能识破'词元撞车'造成的虚假全覆盖。这两行被降级为部分覆盖后，系统自动发起缺口二次检索补足。" |

| 7 | 4:05-4:30 | 右侧文件 tab 全景扫过 + 一条产物详情里的思考过程与成本数字 → 结束标题卡 | "全程七个角色的提示词、思考过程、Token 成本全部可观测可审计——一杯咖啡的时间，完成一周的文献调研初稿。研镜，让 AI 综述可信可用。" |

## 录制要点

1. 每个分镜单独录制片段（便于重录），后期拼接；
2. 审批等待期用剪辑加速（保留进度动效 2 秒即可），标注"加速播放"；
3. 关键术语首次出现时叠加字幕小卡片（覆盖矩阵 / 模型精判 / 引用核验）；
4. 第 4 幕是核心差异化卖点，留足 50 秒；
5. 结尾停留 5 秒纯标题卡："研镜 Research Workbench · VC 团队 · 开放赛题一"。

# 演示视频脚本与录制方案

> 交付要求（附件 1）：时长 ≤ 5 分钟、mp4、体积 ≤ 200M；
> 命名：`XXX（团队名称）_XXX（项目名称）_项目视频.mp4`。

## 录制工具与参数

- 推荐：**OBS Studio**（免费）或 Windows 自带 **Xbox Game Bar**（Win+Alt+R），录浏览器窗口。
- 画面：1920×1080 / 1280×720，H.264，30fps；不录系统音频（本演示无配音，如需旁白另加）。
- 录制对象：浏览器打开 `http://localhost:5173`（本地端），用真实后端 + 真实数据。
- 鼠标指针可见；操作连贯，停顿处剪掉；确认新 UI 字体/间距已到位。
- 涉及个人信息、模型 key 的区域勿入镜；担心可用本地 DEMO 数据跑。

## 5 分钟分镜脚本

| 时间 | 画面 | 要点 | 台词 / 字幕（可选） |
|------|------|------|--------------------|
| 00:00-00:20 | 空态首页 | 一句话定位 + 三痛点 | 研镜：一杯咖啡时间，完成一周文献调研初稿 |
| 00:20-00:40 | 输入研究问题 | 空态输入"研究下多智能体的记忆架构"，点开始 | 只输入一句话 |
| 00:40-01:20 | 规划生成 | Planner 输出子问题/关键词/提纲，停在审批点 | 计划由你审批 |
| 01:20-01:30 | 审批计划 | 点"通过" | 中间过程自动执行 |
| 01:30-02:20 | 检索 | 多源并发 + 工具调用可见，命中/去重 1398 | 多源实时检索 |
| 02:20-02:50 | 筛选 | 候选池 → selector 卡片分级（高/部分）+ 理由 | 标题+摘要筛选 |
| 02:50-03:20 | 写作 | 综述初稿，每个论断带引用标注 | 引用自动标注 |
| 03:20-03:55 | 核验 + 审查 | 引用核验（8 可信 / 1 存疑）+ Concern Ledger | 引用多源交叉核验 |
| 03:55-04:30 | 打回重跑 | 写意见打回 → v2 生成 → 结构差异对比 | 可打回多轮收敛 |
| 04:30-04:50 | 归纳导出 | 主题分组 + 分级 + 引用清单（Markdown / BibTeX） | 结构化导出 |
| 04:50-05:00 | 可观测面板 | 成本 / 思考 / 上下文 / 角色提示词 | 全流程可观测 |

> 时间紧走 4 分钟保底：空态输入 → 规划审批 → 检索 → 筛选 → 写作 → 核验打回 → 收敛 → 导出。

## 录制清单（逐项打勾）

- [ ] 本地服务已启动（server :3000 + web :5173），数据真实/演示
- [ ] 窗口干净、1080p、无无关页面、无个人信息
- [ ] 鼠标可见、操作连贯（先彩排一遍）
- [ ] 结尾停在"导出 + 可观测"高光画面，留 2s 缓冲
- [ ] 导出 mp4，核对 ≤5 分钟、≤200M
- [ ] 命名符合 `团队_项目_项目视频.mp4`

## 可选的 15s 片头

放品牌（研镜 Research Workbench）+ 一句话；用新 UI 首页截图当封面即可，无需专门动画。

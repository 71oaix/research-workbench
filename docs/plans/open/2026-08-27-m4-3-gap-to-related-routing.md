# M4-3 缺口→相关论文路由（plan）

## 任务摘要
无直接专论的子问题，自动做"相关论文路由"：语义改写 → 检索 → 引文雪球 → 挑最相关相邻工作，并标注"无直接专论，以下最接近" + 关联理由。

## 为什么做
用户关心的具体内容常无专门论文；现状只标"缺失"。M4-3 把用户引到**最相关的相邻工作**，让子问题"有着落"。

## 预计效果
- 对无专论子问题给出 ≥1 条相关论文 + 关联理由 + 可支撑程度；并入覆盖矩阵。

## 关键决策
| 决策点 | 选择 | 放弃 | 理由 |
|---|---|---|---|
| 路由 | 语义改写 + 关键词 + 引文雪球 | 向量索引(仍延后) | 不换检索底座仍能提升相关召回 |
| 输出 | 相关推荐（论文+理由+程度） | 只列论文 | 用户能判断 |
| 位置 | 并入 coverage-matrix 的"相关推荐" | 独立文件 | 一处看全 |

## Review 发现与修正
- [major] "相关"判定要避免不相干 → 修正：关联理由必须指明"方法相似/场景相关/可迁移"三选一，并给可支撑程度。

## 实现步骤
1. `buildRelatedSuggestions(gapQuestion, papers)`：改写 → 检索/雪球 → 选最相关 N 条 + 理由。
2. 并入 coverage-matrix 的"相关推荐"栏。

## 测试与验证
- 单测：无专论子问题返回 ≥1 条 + 理由；前端可读。

## 验收标准
- [ ] 无专论子问题给出 ≥1 条相关论文 + 理由 + 程度；typecheck/test 全绿。

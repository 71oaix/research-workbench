# 竞赛演示视频录制（plan）

## 任务解释

交付 9/1 竞赛必需的演示视频：≤5 分钟、≤200M mp4（官方《初赛作品提交规范》硬约束），
真实运行录屏 + 剪映最简剪辑，完整覆盖四"可"叙事。调研已定案（4 路行业调研 +
本机环境实测），本 plan 固化执行步骤。

## 关键决策

| 决策点 | 选择 | 放弃 | 理由 |
|--------|------|------|------|
| 录制工具 | **OBS Studio**（winget 已装 32.2.1，NVENC 硬编） | EV录屏/Game Bar | 免费、可录系统音频、参数可控；EV 需另下 |
| 剪辑工具 | **剪映专业版**（winget 已装 11.3.0，中文/变速/自动字幕） | DaVinci/Premiere | 上手最快，只做"截取+加速+字幕"两步 |
| 录制参数 | 1080p、30fps、H.264（NVENC CQP 16-23），OBS 录 MKV→Remux MP4 | 2K/60fps | 硬约束 ≤200M，1080p30 ≈ 6-8 Mbps 达标 |
| 遍数策略 | **0+1+1+后期**：热身（可跳，历史已验证）→ 真实主录 → DEMO 补拍打回 → 剪辑 | 现场一次成 | 行业共识：分段录制+后期拼是标准 |
| 脚本结构 | 5 列表模板（时间码\|画面\|旁白\|字幕覆盖\|转场），前 8-15s 钩子 | 纯文字稿 | 一行=一镜=一句旁白，脚本先行 |
| 旁白 | **真人录音优先**（Realtek 麦克风阵列），后期对轨 | AI 配音 | 行业实测真人优于 AI（hackathon 评审） |
| 真实性 | 真实运行录屏主体，DEMO 仅补审批打回镜头 | 动画/摆拍 | 官方明令作伪取消资格；决赛可当场质疑 |
| 合规 | 匿名（无校名/导师）、命名 `团队名称_项目名称_项目视频.mp4`、来源可查 | — | 官方硬要求 |

### 步骤 2：真实运行主录（18-25 分钟，不可省）
- [ ] OBS 开始录制
- [ ] 输入问题 → 启动 → **planner 计划审批卡点：先"打回修改"一次**（展示可控：输入一条修改意见 →
      提交 → planner 重跑出 v2 修订计划 → 再点"通过"；只重跑 planner 一步，成本低，意见注入模型 prompt）
- [ ] **writer 成品审批卡点：点"通过"**（第二个审批点；避免打回 writer 触发下游 evaluator/reviewer 重跑，省时间）

- [ ] 中途不停机，任何小失误都录完后期剪
- [ ] 停止录制 → OBS 内"Remux 录像"转 MP4

> 打回意见示例（可直接照抄）："补充近两年多智能体记忆管理的实证研究，并明确与单一智能体记忆方案的对比维度。"

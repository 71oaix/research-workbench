# M4-2 缺口驱动二次检索 + 覆盖矩阵（plan）

## 任务摘要
对未被证据池覆盖的计划子问题，自动做**缺口驱动二次检索 + 重筛**，产出**覆盖矩阵**（子问题→支撑论文→覆盖/部分/缺失→建议）。

## 为什么做
计划常问"特定框架/基准"，而召回不足导致无论文可支撑；现状仅 selector 的"二次检索建议"是建议性的，不会自动补。M4-2 把这变成**自动闭环**。

## 预计效果
- 覆盖矩阵可读；缺口子问题自动补检索；覆盖度量化提升。

## 关键决策
| 决策点 | 选择 | 放弃 | 理由 |
|---|---|---|---|
| 触发 | 覆盖判定"缺失/部分"即自动补检索 | 只输出建议 | 用户要"支撑问题"而非建议 |
| gap 查询 | 子问题原文 + 锚点核心概念 | 仅关键词 | 更贴合子问题 |
| 矩阵 | 覆盖三档 + 关联论文 + 建议 | 只列缺失 | 信息完整 |

## Review 发现与修正
- [major] 覆盖判定要能识别"部分/缺失/覆盖" → 修正：用论文卡片标题/摘要与子问题词元交叠 + 现有主题分组，三档。
- [minor] 补检索可能多轮放大成本 → 修正：与 M4-1 共用 ≤3 轮 + 每轮新论文才重筛。

## 实现步骤
1. `buildCoverageMatrix`；selector 后自动 gap 检索循环；产出 `coverage-matrix.md`。
2. 前端：右"产出文件"加覆盖矩阵，对话流可读（MarkdownView 表格）。

## 测试与验证
- 单测三档判定、自动补检索、上限；真实示例覆盖度对比。

## 验收标准
- [ ] 覆盖矩阵三档可读；缺口自动补检索；≤3 轮；typecheck/test 全绿。

# M3-2 评估与审查增强：六维完整评分制 + 完整性批评视角

## 背景

当前 evaluation-report 是"模型描述式"（主题匹配 / 相关度 / 大纲覆盖 / 来源失败），
是文字结论而非可横向比较的分值；m2-13-effect-audit 建议升级为"六维完整评分制"。
同时 reviewer 为单一角色，主要以 Concern Ledger 抓"引用/证据"类问题，缺少
"完整性批评"视角来自动发现"该覆盖却没覆盖的方向"，而这类发现对答辩最有冲击力
（证明作品知道自己漏了什么）。

## 目标

1. 把评估从"描述"升级为**六维完整评分制**：主题匹配、相关度、大纲覆盖、引用可信、
   来源失败、完整性，每维给分值 + 理由，可横向比较，作为"效果怎么证明"的量化证据
   （进项目文档与答辩）；
2. 新增**完整性批评**视角（reviewer 或评估阶段加一个 critic 角色/提示），自动列出
   值得覆盖却未覆盖的研究方向，作为演示与评估的一部分。

## 范围（做）

- 改造 evaluator：评估 prompt 输出六维分（0-100 或 0-5 分级）+ 每维理由 + 总分；
  解析为结构化数据写入 evaluation-report.md；
- 评估 / review 阶段增加完整性批评输出（覆盖缺口清单，每条一句"缺什么 / 为什么重要"）；
- 前端评估 / 审查 tab 展示六维分与覆盖缺口。

## 不做

- 内容级事实核查（逐句对照全文，延后）；
- 全文 QA（PaperQA2，砍）；
- 改变检索 / 写作管线。

## 验收标准

- [ ] evaluation-report.md 含六维每维分值 + 理由 + 总分，可横向比较；
- [ ] 完整性批评能产出 ≥2 条可操作的覆盖缺口，含"缺什么 / 为什么重要"；
- [ ] 前端评估 / 审查 tab 可读六维分与覆盖缺口；
- [ ] typecheck / test 全绿。

## 关联

- 依赖：M2-13 evaluator（模型评估，已实现）。
- 证据：m2-13-effect-audit 第五节 M3 优先级 3、5。

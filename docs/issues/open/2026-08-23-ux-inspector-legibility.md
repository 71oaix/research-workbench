# UX-4 右侧检查器：可用态区分 + 阅读体验优化

## 背景

- 图 4：右栏 tab / 操作里"能用"和"不能用"的按钮外观几乎一样，分不清哪个可点；
- 右栏是 344px 的狭长列，长文本 / 表格 / JSON 很难读，阅读体验差。

## 目标

1. 交互元素明确区分**可用 / 禁用 / 当前激活 / hover** 四态，让用户一眼知道能点什么；
2. 改善狭长右栏的阅读体验：长文本自适应、表格横向滚动、可折叠/可加宽，避免"看一行翻很久"。

## 范围（做）

- tab / 按钮：统一四态样式（disabled 明显置灰、active 加底色/下划线、hover 反馈）；
- 产物正文：JSON 折叠/格式化、表格横向滚动、窄栏文本换行与字号优化；
- 右栏宽度：允许拖拽或折叠，阅读时看得清。

## 不做

- 不改后端。

## 验收标准

- [ ] 右栏按钮可用/禁用/激活有明显的视觉区分；
- [ ] 长文本与表格在右栏可读（横向滚动/折叠/适配）；
- [ ] 右栏可加宽或折叠。

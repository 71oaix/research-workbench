# UX-5 产物 HTML 展示 + 文献可审批卡片视图

## 背景

- 用户希望**给用户看的产物**是更友好的 HTML 视图（表格、卡片、关键词高亮、文献条目结构化），
  而不是 raw Markdown 文本；agent 间传递仍用 Markdown 输入 + JSON 结构化输出（现状，不改）；
- 图 5：文献/候选清单以一坨 Markdown 文本呈现，用户**无法直观审批文献**（标题/摘要/相关度/
  是否入选看不清，也没有勾选/保留/剔除操作）。

## 目标

1. 产物对用户展示升级为更友好的 **HTML 渲染**（标题分级、表格、卡片、关键词/编号高亮、引用分级）；
2. **文献/候选清单以可审批卡片列表**呈现：每条含标题 / 摘要 / 来源 / 相关度 / 理由，
   支持直观勾选（入选 / 剔除 / 调整相关度），供用户在筛选阶段直接审批。

## 范围（做）

- 前端产物渲染：从 Markdown 升级为结构化 HTML 视图（对 md 产物做表格/卡片化，而非纯文本）；
- 检索/筛选阶段：候选与入选以卡片列表 + 相关度标签 + 操作（保留/剔除/分级）呈现；
- agent 间传递不变：仍 markdown 输入 + json 结构化输出。

## 不做

- 改 agent 间数据格式；不做后端流程重排。

## 验收标准

- [ ] 产物以 HTML 视图阅读（表格/卡片/高亮），`<pre>` 仅用于 JSON/代码；
- [ ] 文献/候选可按卡片直观审批（含相关度标签与保留/剔除操作）；
- [ ] agent 间仍 markdown + json（不破坏现有产物格式）。

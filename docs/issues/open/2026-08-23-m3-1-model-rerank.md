# M3-1 模型精排：候选卡片按细粒度相关度排序

## 背景

M2-15 的 selector 已做"标题 + 摘要"批量筛选并给出相关度分级（高 / 部分 / 剔除），
但最终入选卡片的**排序**仍是候选池顺序 + 简单加权，缺少对"与原查询的细粒度相关度"
的 LLM 精排。m2-13-effect-audit 将"模型精排（卡片相关度加权，PaSa Selector 思路）"
列为 M3 首位，指向的问题：边缘论文进池、相关度 0.10、排名失真。

华为赛题 3.1(3) 明确要求"基于论文标题、摘要及可用全文信息，对候选论文与原始查询进行
细粒度相关性评估，输出经过排序的最终论文列表，区分高度相关和部分相关"——这正是本项目
最贴近赛题评分点、也最容易被评委看懂的能力。

## 目标

在 selector 之后增加（或升级）一个**模型精排**步骤：对入选卡片逐张做"与原始查询的
细粒度相关度"LLM 评分，输出带分值 / 理由的最终排序，作为后续写作、评估与导出的依据。
让"排序"成为可演示（截图分级排序列表）、可量化（分值）的能力。

## 范围（做）

- 新增精排步骤或并入 selector 的 commit：LLM 对候选卡片打分排序，输出排序报告
  （每张卡片：相关度分值 + 一句话理由）；
- 与现有 selector 分级（高 / 部分）衔接，精排决定组内/最终顺序；
- 精排的模型调用、token、成本进入 usage_records 统计；
- 导出与写作基于精排后的顺序。

## 不做

- 向量检索索引（pgvector，recall 上限，延后）；
- 全文 QA（PaperQA2 方向，明确砍）；
- 改动检索源 / 下载管线。

## 验收标准

- [ ] 精排后 final list 每张卡片带相关度分值 + 理由；
- [ ] 一组真实目标（含 M2-16 类目标）能看到精排前后排序变化，并有量化记录；
- [ ] 精排调用数、token、成本进 usage_records，可复现；
- [ ] typecheck / test 全绿。

## 关联

- 依赖：M2-15 selector 分级（已实现）。
- 证据：m2-13-effect-audit 第五节 M3 优先级 1；华为赛题 3.1(3)。

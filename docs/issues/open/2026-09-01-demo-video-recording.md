# 竞赛演示视频录制

> 本 issue 由 `docs/research/2026-09-01-demo-video-production-methodology.md` 调研定案。
> 背景：9/1 提交截止需交付 ≤5 分钟演示视频（≤200M mp4）。用户要求先做行业调查
> （怎么录 / 录几遍 / 怎么写脚本），已出报告，本 issue 把结论固化为可执行任务。

## 背景

- 交付物硬约束：**≤5 分钟、≤200M mp4**（官方《初赛作品提交规范》：时长 ≤5 分钟、大小 ≤200M、
  mp4 格式，命名 `团队名称_项目名称_项目视频.mp4`；研创网线上评审，视频即评委第一印象）；
- **匿名硬要求**：视频片头片尾不得出现学校/学院/导师信息；
- 演示问题固定："研究下多智能体的记忆架构"，目标 4:50；
- 已有两份分镜脚本：`01-competition-story.md`（S1-S10 分镜级 4:50）、
  `2026-08-28-demo-video-script.md`（七幕 4:30）；
- **本机实测未装任何录屏/剪辑软件**，需先装：OBS Studio（录屏）+ 剪映专业版（剪辑），
  winget 均可装（已实测可搜到 OBSProject.OBSStudio 32.2.1、ByteDance.JianyingPro 11.3.0）；
- dev server 运行中，key 已加载（昨日重启过），录制可直接开跑；
- 4 路行业调研已完成（竞赛规范/录屏技术/脚本写作/AI demo 制作），结论见
  `docs/research/2026-09-01-demo-video-production-methodology.md` 及其 companion 报告。

## 目标

- 交付一份 ≤5 分钟、≤200M mp4、可提交、可演示的演示视频；
- 脚本以 4:50 分镜级 S1-S10 为主纲，补齐录制指令 + 旁白逐字稿；
- 按"0+1+1+后期"遍数策略录制：热身 → 主录（真实运行）→ 补拍（DEMO 补审批打回镜头）→ 后期；
- 真实运行全程右栏"运行总览卡"在画面内，特写段（覆盖矩阵/核验报告/总览卡）原速+鼠标指点。

## 范围（做 / 不做）

**做**

- 装 OBS Studio + 剪映专业版（winget）；
- **小修**：`MockStepRunner.ts` 演示官方文档段标题对齐真实文案（"补充参考（官方文档 / 网页，不进引用编号与核验序列）"），避免 DEMO 补拍与真实画面标题不一致；
- 以 01-competition-story.md 分镜为主纲，产出"可录制脚本"（时间码/画面/旁白逐字稿/镜头/转场/字幕/加速标注），按脚本写作调研的 5 列表模板；
- 遍次 0 热身跑通 + 记录特写时间窗（含预置一条 completed + 一条打回迭代历史工作流）；遍次 1 真实运行主录；遍次 2 DEMO 补拍审批打回；
- 剪辑：流程段 4-8x 加速（保留进度动效 2s + 标注"加速"）、特写原速、审批等待跳过、加字幕/关键术语卡、关键帧放大特写；
- 首尾后期素材（开场字卡/幻觉示例图、特性卡动效、指标表叠化、架构图+slogan 卡）；
- 导出 1080p mp4 ≤200M、按官方命名规范，自检通过后提交。

**不做**

- 不做真实"打回重写"镜头（重跑花钱，用 DEMO 模式补拍）；
- 不做向量检索/功能新增（本期纯录制）；
- 不在视频里出现任何真实 key / 敏感信息 / 学校学院导师信息。

## 验收标准

- [ ] 成片 ≤5 分钟、≤200M mp4、1080p 可正常播放，按官方命名规范
- [ ] 无学校/学院/导师信息（匿名合规）
- [ ] 完整覆盖四"可"（可观测/可追踪/可控/可验证）各至少一个镜头
- [ ] 覆盖矩阵 / 核验报告 / 总览卡三个特写原速可读
- [ ] 旁白逐字稿与画面同步，无"念标签"空洞；前 8-15s 为钩子 pitch
- [ ] 全片无：paused spinner、raw English、表格裸奔、key/敏感信息穿帮、空窗 >3s
- [ ] DEMO 补拍与真实画面标题一致（小修后）
- [ ] 提交相关文档（INDEX、runbook 视频节）已同步

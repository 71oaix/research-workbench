# UX-2 澄清审批交互与步骤状态显示

## 背景

- 澄清计划不应放行"通过"：当前是禁用，用户反馈"既然不能通过，直接取消掉通过按钮"；
- 图 2：第一个步骤（规划）已经通过并进入下一轮（计划 v2），但右侧/步骤仍显示"待你审批/需审批"，
  状态与实际不符，用户困惑。

## 目标

1. 存在澄清请求时**不渲染"通过"按钮**（只留"提交回答并重新规划"与"取消任务"）；
2. 步骤状态标签与徽章与**实际状态一致**：已通过/已批准不再显示"待你审批/需审批"；
   判断依据用步骤 `status`，避免残留"需审批"徽章。

## 范围（做）

- ApprovalPanel：澄清时隐藏"通过"按钮；
- StepTimeline / 审批卡：状态徽章严格按 step.status 渲染（approved→已通过；awaiting→待你审批；
  running→进行中），并清除与状态无关的"需审批"残留。

## 不做

- 改后端状态机。

## 验收标准

- [ ] 澄清卡上无"通过"按钮；
- [ ] 已通过步骤不再显示"待你审批/需审批"；
- [ ] 现有 web 测试（含澄清禁用通过用例）更新后仍全绿。

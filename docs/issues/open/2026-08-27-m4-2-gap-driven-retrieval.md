# M4-2 检索/筛选质量门 + 缺口驱动二次检索 + 覆盖矩阵

## 背景

计划中常有**无论文支撑的子问题**（例：要 AutoGen/CrewAI/MetaGPT 记忆机制对比、记忆评测基准，但证据池只有 Mem0）。
根因：检索召回不足，且检索/筛选后**没有"是否覆盖计划子问题"的检查**，缺了也不补。

## 目标

检索/筛选后自动检查**计划锚点 / 子问题是否被证据池覆盖**：

- 未覆盖的子问题转成 **gap 查询**，做二次检索 + 重筛，直到覆盖或达上限；
- 产出**覆盖矩阵**（子问题 / 计划章节 → 支撑论文 + 覆盖/部分/缺失），供用户在对话流直接看；
- 检索不足时自动扩容（同义/相关词、引文雪球、放宽检索），提升召回与覆盖。

## 范围（做）

- 检索/筛选步骤后：从计划提取 子问题/锚点，与证据池（卡片主题/摘要）做覆盖判定；
- 对 coverage=缺失/部分 的子问题，自动生成 gap 查询并二次检索 + 重筛（复用现有 gap 机制，但由"覆盖判定"触发而非仅 selector 建议）；
- 生成 `coverage-matrix.md`（子问题→支撑论文→判定），在对话流/文件 tab 可读；
- 设置最大补检索轮次，达到则如实标注。

## 不做

- 语义向量检索（大幅更换检索基础，仍延后，但本 issue 用查询扩展 + 雪球提升召回）。

## 验收标准

- [ ] 覆盖矩阵可读（子问题/章节 → 论文 → 覆盖/部分/缺失）；
- [ ] 缺失/部分子问题自动触发 gap 二次检索 + 重筛；
- [ ] 一组真实目标前后覆盖度对比有量化提升；
- [ ] 达到补检索上限时如实标注；
- [ ] typecheck / test 全绿。

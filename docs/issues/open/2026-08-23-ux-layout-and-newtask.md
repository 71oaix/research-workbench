# UX-1 布局与新建入口：中央专门输入区 + 详情页空白填充

## 背景

- 新建调研目前是侧栏里一个小弹框（输入 + Writer 勾选 + 创建），非常局促，用户感觉"小家子气"；
- 工作流详情页中心在步骤/审批之间有大片空白（图 1 中部），任务没有填满主区，观感违和。

## 目标

1. 新建调研用**主区专门的输入区域**（大输入框 + 示例 + Writer 选项），不再挤在侧栏小弹框；
2. 详情页中心布局紧凑/填充：审批卡紧跟步骤，空白区用"可观测摘要 / 步骤进度 / 下一步提示"填充，
   或在有大量空白时展示"正在等待/正在处理"的引导内容，避免空旷违和。

## 范围（做）

- 侧栏"新建调研"入口改为打开一个**居中大弹层或主区输入区**（输入框 + 示例问题 + Writer 选项 + 创建）；
- 详情页中心：按工作流状态填充主区（待审批→审批卡紧跟步骤；执行中→流式进度；已完成→成品摘要），
  消除无意义空白。

## 不做

- 不改后端流程；不做响应式大改。

## 验收标准

- [ ] 新建输入不是侧栏小弹框，而是主区/居中大输入区，够大够明确；
- [ ] 详情页中心在常见状态下不再出现大段无内容空白；
- [ ] 现有 web 测试仍全绿。

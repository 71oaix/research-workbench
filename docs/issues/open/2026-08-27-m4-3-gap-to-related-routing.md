# M4-3 缺口→相关论文路由（无专论时引导到最相关相邻工作）

## 背景

用户关心的具体内容常**没有专门论文**去拆解（例如"基于 LLM 的多智能体记忆在长文带读场景的挑战"），
现状只标"缺失/无证据"，无法把用户引到**最相关的论文**，导致子问题看起来"悬空"。

## 目标

对无直接专论的子问题，自动用**语义相关 / 引文雪球 / 相邻文献**找到最相关论文：

- 明确标注：**"无直接专论，但以下相邻工作最接近"**，并给出关联理由（方法相似 / 场景相关 / 可迁移）；
- 把用户关心的具体内容**语义重写为可检索的表述**，再检索相邻文献；
- 结果并入覆盖矩阵与证据池，供用户判断"该用哪个邻近工作支撑这个点"。

## 范围（做）

- 新增"相关路由"能力：对缺失子问题，语义改写 → 检索 → 引文雪球扩展 → 挑最相关 N 条；
- 输出"相关推荐"（子问题 → 相邻论文 → 关联理由 + 可支撑程度），并入覆盖矩阵；
- 前端可读：在覆盖矩阵/相关推荐里看到"无专论，建议这些相邻工作"。

## 不做

- 向量索引（仍延后；本 issue 用改写 + 雪球 + 关键词并集等效提升）。

## 验收标准

- [ ] 对无专论子问题，能给出 ≥1 条相关论文 + 关联理由；
- [ ] 每条相关推荐标注"可支撑程度"（直接/部分/可迁移）；
- [ ] 前端覆盖矩阵/相关推荐可读；
- [ ] typecheck / test 全绿。

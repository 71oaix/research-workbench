# 产物折叠 + 流畅动画 + 思考态视觉

## 背景
综述/候选池产物动辄数屏，对话流被无限拉长；步骤运行期间只有转圈 spinner，缺少 Claude 式"生成中"的视觉质感。

## 目标
1. 产物卡片可折叠/展开，动画流畅无跳变；
2. 长产物（>800 字或 >10 卡）默认折叠；
3. 进度跳转 / 引用定位 / 文件 tab 联动：先展开再滚动；
4. 运行中等待视觉由流式输出（姊妹 issue）承担。

## 范围（做）
- 新增 Collapsible 组件（grid-rows 动画）；ChatFlow 接入折叠头与摘要行；
- 展开联动事件。

## 不做
- 折叠状态持久化；后端改动；分页/虚拟滚动。

## 验收标准
- [ ] 动画流畅无跳变；长产物默认折叠且显示摘要行；
- [ ] 三类跳转必达（自动展开）；
- [ ] 骨架三态截图；typecheck / test 全绿。

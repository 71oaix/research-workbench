# 布局重构 v2：对话流 + 右侧进度跳转 + 版本 tab + 文件 tab（自定义 SVG 图标）

## 背景

现网三栏（左导航 / 中步骤+审批 / 右产物）被用户指出：中间大片空白、右栏狭窄难读、产物靠右侧无法在中间阅读。
已确认新方案（mockup v2.6）：**中间改成对话流**（每步产物按"气泡"依次往下），**右侧为控制区**（顶部执行进度可点击跳转、
底部产出文件 tab），**每张卡片内部用版本 tab 切迭代**（多次打回不新开卡），左侧只留导航；**图标全部用自绘 SVG**。

## 目标

1. 中间 = 对话流：问题 → 规划(计划) → 检索(进度/命中) → 筛选(文献卡片) → 写作(草稿) → 评估 → 审查(意见+审批) → 归纳(摘要)，
   每步产物按气泡渲染，替代"步骤列表 + 窄右栏";
2. 右侧 = 控制区：顶部执行进度（**点击跳转到中间对应气泡**）、底部产出文件 tab（点某文件在对话流定位/查看）;
3. 卡片内版本 tab：同一产物多次迭代（v1/v2/v3）在一个卡片内切换，不新开卡，避免对话流冗长;
4. 底部输入框：新问题 / 回答澄清 / 给修改意见;
5. 图标全部用自绘 SVG 组件（不依赖图标库）。

## 范围（做）

- 重构 App 布局为 [左导航 | 中对话流 | 右控制区]，删除原"步骤时间线 + 右检查器";
- 新增 ChatFlow（每步气泡 + 该步产物渲染 + 内联审批 + 版本 tab）、ProgressRail（可点击跳转）、
  ArtifactFileTabs（产物文件列表）、自定义 SVG 图标集;
- 复用 ApprovalPanel / PaperCards / MarkdownView / WorkflowList。

## 不做

- 改后端流程 / 数据格式（产物仍 markdown+json）;
- 移动端响应式大改（留后续）。

## 验收标准

- [ ] 中间为对话流，每步产物可读（计划/卡片/草稿/摘要），无大片空白;
- [ ] 右侧执行进度可点击跳转到中间对应气泡;
- [ ] 同产物多版本在卡片内 tab 切换，不新开卡;
- [ ] 产物文件 tab 可定位/查看;
- [ ] 图标为自绘 SVG;
- [ ] web typecheck / test 全绿。

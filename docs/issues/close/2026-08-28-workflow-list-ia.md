# 工作流列表信息架构

> 总纲：[2026-08-28-ui-design-review.md](2026-08-28-ui-design-review.md) 专项 4

## 背景

真实库中已有 **44 条工作流**，左栏列表（`WorkflowList.tsx:118-151`）是裸 ul：

1. 全部条目按同一模板渲染，无搜索、无过滤；多轮迭代主题高度相似（截断后全是
   "研究下多智能体的记忆..."），目标工作流只能靠日期肉眼扫——3 条以上就开始痛；
2. 副信息显示 `createdAt · id.slice(0,8)`（WorkflowList.tsx:141）——UUID 前缀对用户
   无意义，是开发者调试信息的泄露；
3. 状态仅靠 6px 色点表达（6 色中 planning/ cancelled 同为灰系），无文字佐证；
4. 空态文案"暂无工作流，先新建一个。"没有引导动作。

## 目标

在 216px 窄栏约束下，让用户 3 秒内定位目标工作流；列表信息对人有意义。

## 范围（做）

- 顶部搜索框（对 goal 前缀/包含匹配，纯前端过滤）；
- 状态过滤 chips（全部 / 进行中 / 待审批 / 已完成，色点+计数，点击切换）；
- 副信息改 `相对时间`（"3 小时前 / 昨天 / 08-20"）+ 状态词（如"已完成"），
  删除 UUID 片段；
- 当前选中项增加左侧 accent 指示条（不只靠白底区分）；
- 空态：图标 + "还没有调研任务"+ 主按钮同款 CTA。

## 不做

- 不做分页 / 虚拟滚动（百级以内前端过滤足够）；
- 不做后端搜索接口；不做排序切换（保持 createdAt 倒序）。

## 验收标准

- [ ] 44 条数据下，按关键词过滤 <50ms 感知即时；
- [ ] 列表无 UUID 泄露；状态过滤 chips 计数正确；
- [ ] 键盘可用（搜索框 Enter 建新、Esc 清除）；焦点样式与全站一致；
- [ ] web typecheck / test 全绿，列表新增交互有组件测试。

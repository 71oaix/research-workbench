# Writing workflow (internalized from nature-writing)

- Start with a one-sentence argument: in [problem] we show [advance] using [approach] supported by [evidence] within [boundary].
- Before drafting, present the one-sentence argument and a short paragraph map; each paragraph does exactly one job.
- Write from evidence outward and keep claims near the evidence that supports them.
- Calibrate verbs to evidence strength: show / demonstrate need strong evidence; suggest / indicate are for weaker support.
- Remove unsupported novelty words such as first, novel, unprecedented, comprehensive.
- End with a claim-evidence map: Claim | Evidence | Status (supported / needs evidence / inferred).
